# Аудит и рефакторинг — 4 октября 2026

Проверены обработчики Telegram, загрузка yt-dlp, выбор форматов, нарезка,
очистка файлов, зависимости и Docker. Новые зависимости приложения не добавлены.

## Исправленные проблемы

| Проблема | Изменение |
|---|---|
| После уменьшения длительности слишком большой части следующий фрагмент начинался со старой границы — кусок видео терялся | Нарезка продвигается по принятой длительности; остаток обрабатывается целиком, ошибка округления не создаёт почти нулевую часть |
| При DASH с неизвестным размером происходило `None + int`; известный размер видео не учитывал аудио | Неизвестный компонент даёт неизвестную оценку; известные размеры видео и аудио суммируются |
| Заявленный лимит трёх загрузок не применялся; два запроса одного пользователя могли пройти до ответа Telegram | Единый обработчик резервирует слот до первого `await`; лишние запросы получают сообщение о занятости |
| Старая кнопка отменяла новую загрузку, чужая кнопка меняла статус владельца | Отмена связана с ID конкретной загрузки; чужому пользователю показывается отдельное уведомление |
| Успешное скачивание могло считаться неудачным из-за лишнего запроса метаданных | Используется результат успешного `extract_info(download=True)`; имена файлов задаются локальным ID |
| Неудачные попытки, отправки и отмены оставляли файлы | Единое владение файлами загрузки, очистка частичных файлов и ожидание пишущего потока перед очисткой |
| ffmpeg/ffprobe могли зависать, некорректная длительность и пустые части не отклонялись | Таймауты 300/30 секунд; проверка конечной положительной длительности и непустого результата |
| Проверка пути не учитывала symlink/junction; URL принимали лишние пути и управляющие символы | Проверка реального пути через `realpath/commonpath`, ограничение поддерживаемыми адресами отдельных видео |
| Тесты обращались к живому YouTube и удаляли рабочий `downloads` | Внешние ответы контролируются, временные файлы изолированы; test-сервис не получает `.env` |
| `make clean-docker` запускал глобальный Docker prune | Очистка ограничена текущим Compose-проектом |

Общая обработка видео вынесена в `media.py`. Удалены дублирование обработчиков,
поиск результата по времени изменения, неиспользуемые вычисления и logger.
Обновлены README и описания архитектуры.

## Безопасность и пределы нагрузки

- Одновременно обрабатываются до трёх заданий; исходный файл ограничен 500 МБ.
  yt-dlp проверяет известный размер и прогресс, после скачивания проверяется готовый
  файл. Это не квота диска: временные дорожки и результаты нарезки занимают дополнительное место.
- Плейлисты и прямые трансляции отклоняются. Сетевой таймаут — 30 секунд,
  ограничены повторы загрузки и фрагментов.
- Пользователь получает нейтральное сообщение вместо текста внутреннего исключения.
  HTTPX/HTTPCore по-прежнему не печатают URL с токеном на уровне INFO.
- `.env.*` исключены из Git, `.env.example` сохранён; cookies остаются только
  в памяти отдельных экземпляров yt-dlp и в исходном read-only mount.
- `pip-audit` проверил 23 установленных Python-пакета: известных уязвимостей
  не обнаружено. Зависимости из `uv.lock` не менялись. Дополнительно просмотрены
  [официальные advisories yt-dlp](https://github.com/yt-dlp/yt-dlp/security/advisories).
- В отслеживаемых файлах не найдены строки формата токена Telegram или приватного
  ключа. Это ограниченная проверка шаблонов текущего дерева, не проверка истории Git.

## Проверки

- Локально: Python 3.14.7, полный pytest — 161 passed; покрытие `bot`, `media`
  и `platforms` — 92% строк.
- Ruff (`F,E9`) и `git diff --check` — успешно.
- Dockerfile: `docker build --check` — без предупреждений.
- Compose: `docker compose --profile test config --no-env-resolution --quiet` — успешно;
  реальные секреты для проверки не загружались.
- Docker test: сборка и запуск `docker run --rm --network none tgdlbot:audit-test
  python -m pytest tests/ -q` — 161 passed на Python 3.14.8.
- Docker production: собран с итоговым кодом; импорт приложения, `appuser`/UID 1000,
  запись в `/app/downloads`, наличие ffmpeg/ffprobe и отсутствие uv/.env подтверждены.
- Реальный ffmpeg в production без сети: синтетический ролик длиной 8 секунд
  разделён на четыре части с видео и аудио. Для небольшой тестовой нагрузки предел
  временно уменьшен до 210 168 байт; части заняли 174 376, 159 999, 146 935 и
  153 112 байт. Длительность каждой — около 2 секунд, очистка всех частей прошла.
  Production использует Python 3.14.8; локальная среда остаётся на 3.14.7.

В локальных тестах остаются три `DeprecationWarning` внутри python-telegram-bot
об `asyncio.iscoroutinefunction` на Python 3.14. Они не скрываются настройками pytest.
Первый sandbox-запуск упёрся в доступ Windows к Temp/cache; повтор с обычными
правами прошёл. Временные каталоги неудачного запуска удалены.

Живые скачивания и отправка в Telegram не выполнялись. Доступность конкретных
YouTube/Instagram-роликов и сессии cookies этим аудитом не подтверждается.
Общая Instagram-сессия по-прежнему предоставляет пользователям бота доступ
к доступным ей публикациям; требование отдельного аккаунта описано в README.
Принудительное завершение процесса или контейнера может оставить файлы;
автоматическое удаление неизвестных старых загрузок намеренно не добавлено.
